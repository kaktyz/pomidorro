# 🍅 Pomidorro

Помидорный таймер для **macOS на Rust**. Полноэкранный терминальный интерфейс
в духе Midnight Commander: панели, управление обычными цифрами, настройки без ввода команд.
Нативный меню-бар, уведомления, затемнение экранов на перерывах и локальная статистика.
Тёмная тема, скруглённые карточки и крупный таймер; тёплый акцент для работы,
мятный — для отдыха. На небольшом экране часы переключаются в компактный вид.

## Запуск

Нужны Rust и Command Line Tools для Xcode (`xcode-select --install`).

```sh
cargo run --release
```

Для установки бинарника в `~/.cargo/bin`:

```sh
cargo install --path . --locked
pomidorro
```

Рекомендуемый размер терминала — **80×28** или больше. Поддерживаются Terminal,
iTerm2 и другие терминалы с ANSI/truecolor. Минимальный размер — 54×19.
На компактном экране часть информационных панелей может быть обрезана.

## Управление

| Клавиши | Действие |
| --- | --- |
| `2`, `Space` | Начать, приостановить или продолжить |
| `3`, `n` | Пропустить этап |
| `4`, `s` | Статистика и история; `↑↓` прокручивают историю |
| `5`, `o` | Настройки |
| `6`, `d` | Включить/выключить затемнение на перерывах |
| `7`, `m` | Включить/выключить сигнал смены этапа |
| `8`, `t` | Проверить уведомления и звук |
| `1`, `h` | Помощь |
| `r` | Сбросить текущий цикл и поставить на паузу |
| `0`, `q`, `Ctrl+C` | Диалог выхода |
| `Esc` | Вернуться к таймеру / отменить изменения |

В настройках: `↑↓` или `Tab` выбирают строку; `←→`, `+/-` меняют значение;
`Space` также переключает выбранный параметр; `Enter` сохраняет все изменения.
Цифры нажимаются без `Fn`; буквенные сочетания также доступны в английской раскладке.
В настройках отображаются контекстные подсказки вместо основных действий; `0` открывает выход.

В диалоге выхода:

- `Enter`, `0` или `q` — завершить таймер и сервис, убрать затемнение;
- `b` — закрыть TUI и **оставить таймер в меню-баре**, в том числе после закрытия терминала;
- `Esc` — отменить выход.

Повторный запуск `pomidorro` подключается к существующему таймеру.
Завершить фоновый процесс также можно через меню-бар → «Завершить Pomidorro».

## Цикл и поведение

- По умолчанию: **25 минут работы / 5 минут отдыха**, после четырёх завершённых
  помидоров — **15 минут отдыха**. Этапы переключаются автоматически.
- Пропуск работы не добавляет помидор в статистику и не увеличивает счётчик цикла.
- Длительности, количество помидоров в цикле и дневная цель меняются в настройках.
  Изменение длительности учитывает уже прошедшее время текущего этапа.
- На паузе затемнение снимается. После сна Mac или задержки обслуживания более
  пяти секунд таймер ставится на паузу: продолжение — `Space` или меню-бар.
- История сохраняет только полностью завершённые рабочие сессии. После полного
  завершения сервиса следующий запуск начинается с нового приостановленного цикла.
- Серия считается по дням, когда достигнута дневная цель (по умолчанию 8 помидоров).
  Незавершённый сегодняшний день не обнуляет серию за предыдущие дни.
  Изменение дневной цели пересчитывает серию по новой цели.
- Статистика за неделю — последние семь календарных дней, включая сегодня.

## macOS-функции

### Затемнение

Во время активного перерыва создаётся полупрозрачное чёрное окно на каждом
подключённом экране. Оно пропускает клики, не перехватывает клавиатуру, доступно
в разных Spaces и поддерживает подключение/отключение мониторов.
Начальная интенсивность — 45%, диапазон — 10–85%.

Аппаратная яркость не меняется. Меню-бар остаётся доступен: убрать затемнение
можно клавишей `d`, из меню-бара, паузой или выходом из сервиса.
Окна находятся на floating-уровне: системные диалоги и некоторые приложения
с собственными elevated-окнами могут отображаться поверх затемнения.

### Уведомления и звук

Уведомления отправляются системным `osascript`, с заголовком **Pomidorro**.
В настройках уведомлений macOS их источник — **Script Editor / Редактор скриптов**.
Нажми `t` для проверки и разреши уведомления этого источника в
**Системные настройки → Уведомления**. Режимы фокусирования macOS могут скрывать баннеры.

Сигнал смены этапа использует системный звук `Glass`; опциональное тихое тикание
во время работы — `Pop`. Тикание по умолчанию выключено и настраивается отдельно
от сигнала смены этапов. Звуки воспроизводятся через штатный `afplay`.

## Данные

Всё хранится локально:

```text
~/Library/Application Support/dev.pomidorro.Pomidorro/
├── settings.toml   # настройки
├── sessions.json   # история завершённых сессий
└── service.log     # диагностика фонового процесса
```

Настройки и история записываются через временный файл и атомарное переименование.
Некорректные файлы не перезаписываются: ошибка будет показана при запуске.
Для ручного редактирования настроек сначала заверши сервис через TUI или меню-бар.

TUI общается с сервисом по Unix-сокету `/tmp/pomidorro-<uid>/service.sock`.
Каталог доступен только текущему пользователю. Сервис запускается автоматически;
`--service` — внутренний аргумент, для обычного использования не нужен.

## Структура

```text
src/
├── main.rs       # запуск
├── model.rs      # ядро таймера, настройки, статистика
├── tui.rs        # ratatui + crossterm
├── service.rs    # macOS event loop, меню-бар, AppKit overlay, эффекты
├── ipc.rs        # типизированный JSON-протокол по Unix-сокету
└── storage.rs    # сохранение настроек и истории
```

TUI и сервис — два процесса одного бинарника. AppKit и меню-бар обслуживаются
на главном потоке сервиса, терминал — в процессе TUI. Веб-интерфейс и Node.js не нужны.

## Проверки

```sh
cargo fmt --check
cargo test
cargo clippy --all-targets -- -D warnings
cargo build --release --locked
```

Автоматические тесты проверяют полный цикл, паузы, границы этапов и календарные серии.
Для ручной проверки интеграций: `Space`, `n` (активный перерыв с затемнением),
`d` (отключение затемнения), `t` (уведомление и звук), затем `q` → `Enter`.
